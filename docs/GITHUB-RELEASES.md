# GitHub Releases

## Distribution policy (current)

| Platform | Channel |
| --- | --- |
| **Windows portable BETA** | GitHub **Latest** release zip: `EG-Launcher-*-win-x64-portable-BETA.zip` (unsigned; SAC/SmartScreen may warn). In-app **BETA** badges stay. |
| **Linux** | **GitHub Releases** — `EG-Launcher-*-linux-*.AppImage` |

There is **no Microsoft Store** listing. Windows users use the portable zip (or a local self-build).

Background on unsigned Windows binaries: **[GITHUB-SAC.md](./GITHUB-SAC.md)**.

---

## CI workflow

`.github/workflows/release.yml` — **Build & Release**

Preferred for public tags:

1. Build **Linux AppImage only** (no Windows setup/uninstall on GitHub)  
2. Publish release notes (changelog)  
3. Windows Store AppX is built separately via `npm run dist:store` (not this workflow)

Historical releases may still list old `.exe` assets; treat those as **unsupported**. New releases ship **Linux AppImage only** on this repo.

---

## Cut a Linux GitHub release

1. Bump `package.json` + `shared/branding.ts` (`APP_VERSION`).  
2. Add `CHANGELOG.md` section for that version.  
3. Commit, push `master`.  
4. Tag:

   ```bash
   git tag vX.Y.Z
   git push origin master
   git push origin vX.Y.Z
   ```

5. Wait for Actions → green. Confirm **AppImage** asset.  
6. Do **not** advertise Windows setup on the release body (banner is generated by `scripts/extract-changelog.mjs`).

### Local Linux AppImage

```bash
npm ci
npm run dist:linux
```

### Windows portable BETA (local)

```bash
npm run dist:win-portable
```

Produces `release/EG-Launcher-<version>-win-x64-portable-BETA.zip`.

## Support (copy-paste)

**Where is the Windows installer?**

> There is no Microsoft Store listing and no public `setup.exe`. Download the **portable BETA zip** from GitHub Releases, unzip, and run `EG Launcher.exe`. SmartScreen may warn because the zip is unsigned.

**Linux**

> Download the AppImage from https://github.com/YourLovelyFox/eg-launcher/releases/latest then `chmod +x` and run it.
